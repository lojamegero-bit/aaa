# ZBM UI SYSTEM v1.1 — 一括テスト用

v1.0の実ファイルを基準に、ターコイズの配色、上寄せパネル、段階的な開閉を残して作り直した3種類のFusion Titleです。大きな英語見出し、多重枠、キャラクター入力を削除しました。別のインフォグラフィックは使用していません。

**Resolve実機テスト前のパッケージです。Windows／DaVinci Resolve 21無料版のインストール、Loaderのインスペクタ表示、画像の寸法処理、尺変更、書き出し、4K再生性能は未検証です。** プレビューはPython/PillowとFFmpegによる説明映像で、Resolveの出力ではありません。

## 最初に使うもの

1. ZIPを右クリックして「すべて展開」。Resolveを終了します。
2. 展開先でPowerShellを開き、`& .\install_windows.ps1` を実行します。組織等のスクリプト実行制限がある場合はポリシーを変更せず、下記の手動導入を使います。
3. Resolveを起動し、エディットページのエフェクトライブラリ → タイトルで `ZBM` を検索します。
4. `ZBM_COMPARISON_v11`、`ZBM_REFERENCE_v11`、`ZBM_DETAIL_v11` を映像の上のトラックへ各4秒配置します。実際の表示名やフォルダ表示は実機確認が必要です。
5. 各タイトルのインスペクタで **タイムラインFPS** をタイムラインのFPSへ合わせます。29.97と30、59.94と60も区別します。
6. 画像・文字・位置・倍率を設定し、`Docs/実機テスト.md` の全3種を一括で確認します。

インストーラは専用v1.1フォルダだけを使い、v1.0を変更しません。再導入は `& .\install_windows.ps1 -Force`。設定はバックアップしますが、同梱UI・サンプルPNGは再コピーします。Assetsは既存プロジェクトが参照する間は削除しないでください。

## 画像交換・配置

内蔵LoaderのClipを「画像1を選択」「画像2を選択」として公開しています。外部ノードへの接続をなくす設計ですが、**エディットページでこのファイル選択欄が操作できるかは実機未検証です。** 表示されればPNG/JPEG等の静止画を指定します。動画・シーケンスは対象外です。ファイルの移動や別PCへの移行後はパスの再設定が必要です。

固定スロットで切り抜きます。画像ごとの位置・倍率を調整し、必要な部分を表示してください。自動フィット・自動被写体追跡はありません。画素数・縦横比により画角が異なります。画像の端が見える場合は倍率を上げます。細部の解像度には高解像度の原画像が必要です。

### 画像欄が使えない場合：ノード操作なしの代替

Resolveを終了し、展開フォルダから次の例を実行します。パスは自分の素材へ変更します。

```powershell
& .\set_images_windows.ps1 -Template COMPARISON -Image1 'D:\模型\改修前.jpg' -Image2 'D:\模型\改修後.jpg'
& .\set_images_windows.ps1 -Template REFERENCE -Image1 'D:\模型\資料.png'
& .\set_images_windows.ps1 -Template DETAIL -Image1 'D:\模型\拡大.jpg'
```

素材を専用AssetsへPNGとして保存し、インストール済みタイトルの既定画像を変更します。原画像は変更せず、画素数を保持します。大きすぎる原画は先に必要な解像度へ縮小してください。Windows/System.Drawingで開ける静止画が対象です。この補助スクリプトもWindows実行は未検証です。

再起動後、**新しいタイトルを配置**してください。配置済みのタイトルは更新しません。複数の比較は「既定画像設定 → 再起動 → 新規配置」を繰り返せますが、頻繁な交換には不便です。公開画像欄が使えない場合、エディットページだけでの手軽な交換という目標は未達となるため、実機テストで優先して報告してください。

## 文字・長さ・字幕

- COMPARISON：左右の短いラベル。不要なら空にします。
- REFERENCE：説明と任意の出典。手動改行を入れ、1行全角12〜15字程度、最大6行を目安にします。長文は文字サイズを小さくするか、タイトルを分けます。自動縮小・自動ページ送りはありません。
- DETAIL：画像下の短い説明。不要なら空にします。
- フォント初期値はYu Gothic。未導入／文字化けならインスペクタで日本語フォントへ変更します。プレビューはNoto Sans CJKなので、実機と字形・改行位置は異なります。
- クリップ端をトリムして尺を変更します。開き約0.5秒、閉じ約0.18秒、1秒以上を想定。Fusion Titleのcomp.RenderStart/RenderEndとトリム後の範囲が一致するか、実機で閉じを確認してください。
- 初期状態でパネル下端は画面下から20%。字幕はこの下へ配置します。UI全体を移動・拡大した場合は干渉を再確認してください。
- 内部キャンバスは3840×2160固定。UHD 4K・16:9向けです。DCI 4K、縦動画、他の縦横比やHDへの自動適応は検証対象外です。

## 手動導入

1. `Assets` の全PNGを `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\ZBM_UI_SYSTEM_v1_1\Assets` へコピー。
2. `Templates` の3つの`.setting`をテキストエディタで開き、`__ZBM_ASSET_ROOT__` を上のAssetsの絶対パスに置換。区切りは `/` を使います。例：`C:/Users/ユーザー名/AppData/Roaming/Blackmagic Design/DaVinci Resolve/Support/Fusion/ZBM_UI_SYSTEM_v1_1/Assets`。
3. UTF-8 BOMなしで `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles\ZBM UI v1.1` へ保存。
4. Resolveを再起動します。未置換のTemplatesファイルを直接ドラッグしても画像は解決しません。

アンインストールはResolve終了後、専用タイトルフォルダを削除します。Assetsは既存プロジェクトが使う間は残します。

## 同梱物・制限

`Templates`：3種類。`Assets`：4K透明UI・デモ画像。`Preview`：説明用動画・静止画。`Docs`：実機テスト、設計、検証結果。`Source`：レイアウト、ノード数、Lua検査スクリプト。`SHA256SUMS.txt`：同梱物のハッシュ。

サンプルは支給v1.0のプレビュー静止画から切り出した低解像度画像で、原写真ではありません。本番と画質テストには自分の原画像を使ってください。

`.drfx`と`.drp`は同梱していません。実機で生成していないプロジェクトを有効なResolveファイルとして扱わず、素材パスを導入時に設定するPowerShell方式としました。
