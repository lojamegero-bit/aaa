# 技術設計・検証範囲

## v1.0実ファイルの確認

COMPARISONは52ノード（Background 12、RectangleMask 13、Merge 18、TextPlus 4、Transform 4、CustomTool 1）、REFERENCEは49、DETAILは44。背景・見出し・枠・画像・文字を時間差で展開し、幅・高さ・ブレンド・文字Alphaに開始からの経過時間と終了までの残時間を使う式を持ちます。元の合成マクロは外部画像ノードの接続が必要でした。

多数のフルフレーム合成、元画像の解像度、マスク、GPUメモリ、キャッシュ状態は負荷候補ですが、分離した実機計測はありません。52という数から原因を断定しません。

## v1.1構造

4K RGBA PNGにパネル、上辺の細線、仕切り、画像スロット背景を集約。透明BackgroundへUIを1回合成し、静止画Loaderを矩形マスクで合成、編集可能なTextPlusを重ね、最後に全体位置・倍率を調整します。外部OFX、Fuse、グロー、ブラー、パーティクル、Studio専用機能は要求しませんが、無料版Resolve 21での動作保証ではありません。

COMPARISON 16ノード、REFERENCE 13、DETAIL 11。内訳はSource/node_counts.json。ノード削減だけを軽量化実績とせず、多層の装飾処理を静的素材へ置き換える構造変更です。Loaderのキャッシュ再利用はホスト次第。4K RGBA 1面は8bitで約31.6MiB、float RGBAで約126.6MiB。実バッファ数、VRAM、再生FPS、書き出し時間は未測定です。巨大原画のデコード負荷は残ります。

動作：パネル0〜0.20秒、画像1 0.12〜0.38秒、画像2 0.18〜0.44秒、文字0.31〜0.50秒。終端0.18秒でパネル・画像は幅を縮め、文字は消えます。保持中は静止。v1.0の段階的展開の構成を継承し、全装飾の動作をそのまま複製したものではありません。

FPSは手動公開値。多数のGetPrefs呼び出しをなくし、利用者がタイムラインに合わせます。comp.RenderStart/RenderEndがトリム後の範囲と一致するかは実機の必須確認です。

## 未解決事項と代替操作

- Loader Clipの公開欄がEditで操作できるかは未確認。画像設定用PowerShellを同梱していますが、既定画像を変更した後に再起動・新規配置が必要です。配置済みタイトルの画像交換の代替にはなりません。
- 自動画像フィットはありません。位置・倍率を手動調整します。Mergeが元画像サイズをどう扱うか、縦横比を含め実機確認が必要です。
- 説明文の自動縮小・自動ページ送りはありません。改行・サイズ変更・表示分割で対応します。長文自動レイアウトは未達です。
- 内部キャンバス3840×2160固定。他の縦横比への自動適応は未提供。
- プレビューはPillowで写真をスロットへfitした概念映像。Resolveの画角・フォント・アルファ処理の再現ではありません。
- Windows用スクリプトはWindows実行未検証。実機で出力したdrfx／drp、性能ベンチマークは未提供。

生成・静的検査・プレビュー確認が完了した状態と、実用性能が確認された完成品を区別します。実機テストの優先順位は画像交換、尺追従、4K性能です。
